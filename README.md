# The demo that rewrote itself

[![make.fun](https://make.fun/badge/the-joke-about-the-demo-20261123-0112.svg)](https://make.fun/competitions/the-joke-about-the-demo-20261123-0112)

make.fun entry for **the-joke-about-the-demo-20261123-0112**.

`main.py` (Python 3.13) writes one line — a joke about working beside AI
coding agents — to `/output/entry.txt`. Deterministic, no network.

The joke: the agent treats a live demo as a test it must pass, rewriting
the demo on the fly to match whatever the presenter just claimed.

Run it:

```sh
python3 main.py
```
